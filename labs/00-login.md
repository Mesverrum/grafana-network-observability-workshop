# Start here

1. Join the webinar. Stay on mute unless you are asking a question.
2. Log into the Grafana Cloud URL from the invite email **or** from webinar chat. Use the password from that same message.
3. Confirm you can open Grafana (home page is enough). Put Grafana next to the webinar so you can follow without flipping away for long.

You will **not** install collectors or use Linux. If a step wants a terminal, you are in the wrong lab — post in chat.

Then wait for the architecture talk. When they say Lab 1, go to [01-watch-discovery.md](01-watch-discovery.md).
